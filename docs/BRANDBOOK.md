# Брендбук Pinhead Studio — что из него берёт сайт

Источник — гайдбук розничного направления v1.1 (PDF у владельца проекта; макет в Figma «ПИНХЕД ДЛЯ СДАЧИ»).
Сайт следует ему; отступления записаны ниже.

## Логотип
- Основная версия — горизонтальная: «пинхэд ® ✱ студия», знак-«игла» между начертаниями. Есть версия в две строки
  и раздельные (только знак; «пинхэд / студия» без знака). Знак ® можно убирать на малых размерах.
- На сайте — кириллическая версия (`public/brand/logo-ru*.svg`).
- Охранная зона — 2X вокруг логотипа (X — высота строчных букв).

## Цвета
- Основная палитра: салатовый `#B4FB53`, синий `#1D19EA`, чёрный, белый. Салатовый и синий — акценты.
- Расширенная палитра — оттенки основных цветов с шагом 10 %.
- Фирменный градиент — металлизированный (чёрный → белый с зерном), только для акцидентной графики.

## Шрифты
- Заголовки — по брендбуку Heading Pro Compressed Bold (Zetafonts). **На сайте — Roboto Condensed Black**: решение
  владельца 22.11 (сравнили вживую — Roboto Black шире и лучше читается в наших заголовках). Вернуться к Heading Pro —
  только с купленной веб-лицензией; пробные файлы Zetafonts для сайта не годятся (нет цифр, личная лицензия).
- Текст — Roboto Condensed.

## Графика
- Графический мотив — «иглы»: резкие тонкие царапины, небрежные линии ручной работы.
- Знак можно по-разному интерпретировать (12 вариантов звёздочки в гайде) — как вспомогательную графику.
- Маркировки — 10 знаков-«иголок»: ®, прицел, прицел с кольцом, мишень, «паутинка», плюс с точкой, звёздочка
  с точкой, восьмилучевая звезда, «вспышка», косая «вспышка». Файлы — `public/brand/marks/*.svg`,
  компонент — `site/brand-mark`.
